# Orbtile Homebrew tap

Install Orbtile, the status pad for AI coding agents, on a Mac with Homebrew:

```sh
brew install --cask orbtile/tap/orbtile
```

This repository holds only the cask file (`Casks/orbtile.rb`): the version, the download link on orbtile.com and the installer's SHA-256. Orbtile is signed with an Apple Developer ID and notarised. Each release updates the cask.

More: https://orbtile.com
